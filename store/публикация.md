# Как опубликовать расширение в магазинах

Репозиторий: https://github.com/Pojar686/tl-mr100-ru
Политика конфиденциальности: https://pojar686.github.io/tl-mr100-ru/store/privacy-policy.html

## 1. Chrome Web Store (официальный магазин Google)

Что нужно:
- аккаунт Google;
- разовый взнос разработчика 5 $ (карта, оплата один раз на аккаунт);
- zip-архив: `dist/tl-mr100-ru-1.0.1.zip` (манифест лежит в корне архива — так и надо);
- иконка 128×128 (есть: `chrome-extension/icons/icon128.png`);
- скриншоты 1280×800 (готовы: `store/screenshot-1-karta-seti-1280x800.png`,
  `store/screenshot-2-internet-1280x800.png`);
- ссылка на политику конфиденциальности (см. `store/privacy-policy.html`).

Шаги:
1. https://chrome.google.com/webstore/devconsole — войти, оплатить регистрацию.
2. «New item» → загрузить zip.
3. Заполнить карточку текстами из `store/listing-ru.md`.
4. Вкладка «Privacy practices»: отметить, что данные не собираются,
   обосновать доступ к сайтам (текст есть в listing-ru.md).
5. Отправить на проверку. Обычно 1–3 рабочих дня, иногда дольше.
6. После публикации даёте друзьям ссылку — установка в один клик.

Нюанс: у Google бывают придирки к расширениям, которые работают только
на локальном IP. Если ревью завернут — второй аргумент: это официальный
перевод от самого производителя, просто перенесённый в браузер.

## 2. Яндекс.Расширения (выбранный вариант — проще всего)

1. Открыть https://addons.yandex.ru/ → «Войти» (обычный Яндекс-аккаунт) →
   «Стать автором» / «Загрузить расширение».
2. Загрузить `dist/tl-mr100-ru-1.0.1.zip` (манифест уже в корне).
3. Заполнить карточку текстами из `store/listing-ru.md`:
   название, краткое и полное описание, категория «Инструменты».
4. Иконка — `chrome-extension/icons/icon128.png` (512×512 подойдёт
   `icon512.png`).
5. Скриншоты — `store/screenshot-1-karta-seti-1280x800.png` и
   `store/screenshot-2-internet-1280x800.png`.
6. Ссылка на политику конфиденциальности:
   https://pojar686.github.io/tl-mr100-ru/store/privacy-policy.html
   (исходник — `store/privacy-policy.html` в репозитории).
7. Отправить на модерацию. Взноса нет, проверка ручная — обычно несколько дней.
8. После публикации даёте друзьям ссылку на карточку — установка в один клик.

## 3. Microsoft Edge Add-ons

1. https://partner.microsoft.com/dashboard/microsoftedge/overview
2. Регистрация бесплатная (нужен аккаунт Microsoft).
3. Загрузить тот же zip, карточка по тем же текстам.
4. Проверка обычно 1–7 дней.

## 4. Firefox (AMO) — нужна отдельная сборка

В Firefox нет `world: "MAIN"` в манифесте, поэтому zip для Chrome там не заработает.
Вариант проще: опубликовать userscript `tplink-mr100-ru.user.js` в Greasy Fork
и дать ссылку — пользователи ставят через Tampermonkey за 2 клика.

## Чего делать не надо

- Не распространять .crx: Chrome/Edge/Яндекс блокируют установку .crx не из магазина.
- Не пытаться «подписать» расширение — для магазинов подпись делает сам магазин.
