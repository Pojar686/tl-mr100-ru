# Карточка в магазине расширений

## Название (до 45 символов)
TL-MR100 — русский интерфейс

## Краткое описание (до 132 символов)
Возвращает русский язык в веб-интерфейс роутера TP-Link TL-MR100 v3 (прошивка 1.7.0 и новее). Без перепрошивки.

## Подробное описание
Прошивка 1.7.0 для TP-Link TL-MR100 v3 лишилась русского языка: в интерфейсе остался только английский.

Это расширение возвращает русский интерфейс — но только в браузере. Роутер не перепрошивается, настройки, гарантия и безопасность устройства не затрагиваются, откатить ничего не нужно.

Что переводится:
• всё левое меню и вкладки (Карта сети, Интернет, Беспроводной режим, Гостевая сеть, Родительский контроль, Защита, VPN и т.д.);
• кнопки, подписи полей, подсказки «?»;
• статусы (состояние SIM-карты, уровень сигнала, тип сети, скорости);
• сообщения об ошибках и экран входа.

Откуда перевод: официальный русский язык из прошивки 1.6.0 (2820 строк). Строки, которые появились только в 1.7.0 (VPN-клиент/сервер, IPSec, Cell ID Lock, IPv6 Firewall и др.), переведены вручную — всего 189 строк.

Важно:
• список языков в интерфейсе остаётся «English» — перевод включается автоматически при каждой загрузке страницы;
• расширение работает только на адресах роутера: http://192.168.1.1/ и http://tplinkmodem.net/ (и их https-вариантах);
• никакие данные не собираются и никуда не отправляются: расширение не делает сетевых запросов и не имеет доступа к другим сайтам.

Поддерживаемые браузеры: Chrome, Яндекс.Браузер, Edge, Opera, Vivaldi (Chromium 111+).

## Обоснование разрешений (для проверки)
Расширение не запрашивает permissions. Единственное, что указано в манифесте, — content_scripts.matches для двух локальных адресов роутера (192.168.1.1 и tplinkmodem.net). Это нужно, чтобы подменить словари локализации в памяти страницы. Сетевых запросов расширение не выполняет, данные не собирает и не передаёт.
