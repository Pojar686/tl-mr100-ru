# Русский интерфейс для TP-Link TL-MR100 v3 (прошивка 1.7.0+)

Прошивка 1.7.0 лишилась русского языка. Этот набор возвращает русский интерфейс
**только в вашем браузере** — роутер не перепрошивается, гарантия и настройки не затрагиваются.

Что переводится: всё меню, кнопки, подписи, статусы, сообщения об ошибках,
всплывающие подсказки и экран входа. Источник перевода — официальный русский язык
из прошивки 1.6.0; строки, появившиеся только в 1.7.0 (VPN-клиент/сервер, IPSec,
Cell ID Lock, IPv6 Firewall и др.), переведены вручную.

## Вариант 1. Расширение для Chrome / Edge / Яндекс.Браузера (рекомендуется)

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите «Режим разработчика» (Developer mode).
3. Нажмите «Загрузить распакованное расширение» (Load unpacked).
4. Выберите папку `chrome-extension` из этого каталога.
5. Откройте или перезагрузите `http://192.168.1.1/` — интерфейс будет на русском.

## Вариант 2. Tampermonkey / Violentmonkey

1. Установите расширение Tampermonkey (или Violentmonkey).
2. Откройте панель Tampermonkey → «Создать новый скрипт».
3. Удалите шаблон и вставьте всё содержимое файла `tplink-mr100-ru.user.js`.
4. Сохраните (Ctrl+S) и перезагрузите страницу роутера.

## Раздать друзьям

- `dist/tl-mr100-ru-1.0.1.zip` — готовый архив расширения (манифест в корне, ставится
  через «Загрузить распакованное расширение»). Рядом лежит `dist/КАК-УСТАНОВИТЬ.txt`
  с инструкцией для человека, который никогда этого не делал.
- `store/` — всё для публикации в магазинах: `listing-ru.md` (название, описания,
  обоснование разрешений), `privacy-policy.html` (политика конфиденциальности),
  `публикация.md` (пошагово: Яндекс.Расширения, Chrome Web Store, Edge) и два готовых
  скриншота 1280×800 (`screenshot-1-karta-seti-1280x800.png`,
  `screenshot-2-internet-1280x800.png`). Скриншоты в публичный репозиторий
  не выкладываются — на них данные устройства.

Почему zip, а не `.crx`: Chrome, Edge и Яндекс.Браузер блокируют установку `.crx`
не из магазина. Zip + «Загрузить распакованное» работает везде, где есть Chromium.

## Примечания

- Язык в выпадающем списке останется «English» — это нормально: перевод
  принудительно включается скриптом при каждой загрузке страницы.
- Новые устройства/языки не затрагиваются: скрипт работает только на адресах
  роутера (192.168.1.1 и tplinkmodem.net).
- Если после обновления прошивки появятся новые строки, они останутся английскими —
  словарь можно дополнять.
